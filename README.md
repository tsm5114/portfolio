# 陶诗曼 · 个人作品集

个人商业分析与运营策略作品集网站。

## 新版站点（V2.0）

新版作品集位于 `portfolio/`，基于 Vite + 原生 JavaScript 多页面应用构建。

- 首页：Hero / About / Selected Works / Experience / Contact
- 5 个项目详情页：小红书电商运营、飞书加分管理系统、跨境电商出海方案、电商用户行为分析、AI 大模型行业研究

**启动 / 构建 / 部署 / 内容更新说明见 [`portfolio/README.md`](portfolio/README.md)。**

```bash
cd portfolio
npm install
npm run dev       # 本地开发
npm run build     # 构建到 portfolio/dist/
```
